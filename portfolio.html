통역 한 번이 흘러가는 길

아이폰 → 중계 서버 → 통역 서버 → 이어폰

  1. 듣기

    아이폰 마이크가 주변 외국어를 받아 LiveKit(실시간 음성 중계 서비스)으로 끊지 않고 보냅니다.

  2. 통역

    Python 통역 서버가 그 소리를 Gemini Live에 계속 흘려 넣고 한국어 음성으로 돌려받습니다.

  3. 자막

    원문과 번역을 문장 단위로 짝짓고, 글자 모양으로 언어를 가려 [영어]·[일본어] 표시를 붙입니다.

  4. 귀로

    한국어 음성은 연결된 에어팟·갤럭시 버즈·블루투스 이어폰·MFi 보청기로 나가고, 화면에는 자막이 추가됩니다.

통역이 멈추지 않게 바꾼 과정

개발 기록 · 통역 서버 코드

  1. 문제

    처음에는 말이 끊긴 틈을 찾아 그때마다 통역을 요청했습니다. 통역 음성이 마이크로 되돌아와 다시 통역되거나, 첫 문장 뒤 또는 약 20초 뒤에 통역이 멈췄습니다.

    끊길 때 요청
  2. 판단

    Gemini Live 통역 모델은 소리를 끊지 않고 계속 받도록 만들어졌다고 보고, 말 끊김을 찾는 장치(휴대폰 쪽 음성 감지, Gemini 자동 발화 감지)를 모두 껐습니다.

  3. 검증

    남은 멈춤은 오류 번호로 하나씩 추적했습니다. 라이브러리가 자동으로 보내던 응답 요청은 가로채 막았고, 마이크를 직접 끄면 이어폰 소리까지 멈춰서 대신 모델에게 한국어 음성은 무시하라고 지시했습니다.

  4. 결과

    통역, 음성 출력, 보청기 연결이 한 흐름으로 이어서 동작합니다. 같은 연결 위에 받아쓰기만 하는 회의록 모드도 추가했습니다.

글자 범위만 보고 원문 언어를 고름

여러 언어가 섞인 대화에서는 지금 들은 말이 무슨 언어였는지 알려 줘야 합니다. 번역 서비스에 언어를 물으면 기다리는 시간이 늘어나서, 통역 서버 안에서 글자 범위로 바로 판단하게 했습니다.

  • 한글이 있으면 한국어, 가나가 있으면 일본어
  • 한자만 있으면 중국어, 알파벳이 30%를 넘으면 영어
  • 결과는 자막과 함께 앱으로 보내 [영어]·[일본어] 표시로 띄움
